Polyglot Microservices Pipeline

One release process for Java and Python services, with security checks and system monitoring.

Engineering labTypeEngineering labServicesJava + PythonDeliveryJenkins + Docker
Overview · Cloud & platform engineering

Two languages. One delivery system.

A platform that runs Java application services and Python analytics together on Amazon EKS. Spring Boot and FastAPI services share one process for releasing updates, checking security and monitoring health.

The Engineering

Decisions that shape the system.

01

A runtime for each job

Java 21 and Spring Boot 3 handle core APIs. Python 3.12 and FastAPI handle asynchronous analytics. PostgreSQL provides the relational data layer.

02

Build once, release deliberately

Jenkins builds multi-stage Docker images under 200 MB, scans them with Trivy and deploys to EKS, with non-root containers and Vault-backed secrets.

03

Operate from signals

TLS ingress, autoscaling and zero-downtime rollouts support continuity; Prometheus and Grafana track rate, errors and duration with alerts.
