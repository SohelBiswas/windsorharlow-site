Delivery

Source changes enter Jenkins for tests, multi-stage image builds and Trivy scans. Published images feed the EKS deployment workflow.

Runtime

TLS ingress routes traffic to Spring Boot APIs and FastAPI analytics. Kubernetes manages replicas and health-aware rolling updates; PostgreSQL serves the data layer.

Operations

Vault supplies application secrets. Prometheus collects service metrics, while Grafana exposes rate, error and duration signals and alerting.

The engineering

Decisions that
shape the system.

A platform that runs Java application services and Python analytics together on Amazon EKS. Spring Boot and FastAPI services share a process for releasing updates, checking security and monitoring system health.

01A runtime for each job+

Java 21 and Spring Boot 3 handle core APIs. Python 3.12 and FastAPI handle asynchronous analytics. PostgreSQL provides the relational data layer.

02Build once, release deliberately+

Jenkins pipelines build multi-stage Docker images under 200 MB, scan them with Trivy and deploy to EKS. Non-root execution and Vault-backed secrets keep security in the delivery path.

03Operate from signals+

TLS ingress, horizontal pod autoscaling and zero-downtime rollout configuration support service continuity. Prometheus and Grafana track rate, errors and duration, with alerts for latency and error spikes.

04Stack & capabilities+
  • Polyglot servicesSpring Boot APIs and FastAPI analytics.
  • Jenkins deliveryBuild, scan, publish and deploy.
  • Workload securityNon-root containers and Trivy scans.
  • Vault secretsSecrets separated from container images.
